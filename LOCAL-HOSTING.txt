FRAME Eyewear — local setup

1. Extract FRAME-eyewear.zip.
2. Open the extracted FRAME-eyewear folder in VS Code.
3. Install Node.js 18 or newer if it is not installed.
4. Open Terminal > New Terminal in VS Code and run: npm start
5. Visit the localhost address printed in the terminal (usually http://localhost:8000). If port 8000 is busy, the server automatically tries the next available port. Leave the terminal running.

The server creates data/store.json for persistent local products, accounts, orders, ratings, and helpline settings. Default demo admin password: admin555.

The checkout records orders but does not charge UPI/cards or book a courier. See README.md before using this for a public store.

Admin product photos: open Admin portal > Products > Product photos from this Mac, select up to 3 pictures, and click Add product. Images are stored in the project uploads/ folder.
Checkout: sign in or create an account, add products to the bag, then enter recipient, mobile, 6-digit PIN, address, city, state, and choose COD or UPI. UPI payment collection needs a payment gateway and is not activated in this local build.

PERSISTENCE: Server data is saved outside this project in ~/.leux-optics/store.json and ~/.leux-optics/uploads/. The server prints these exact paths at startup and automatically migrates data/store.json plus uploads/ from this project on first run. Back up the entire ~/.leux-optics folder. If updating into a fresh extracted folder, copy the old project data/store.json and uploads/ into the new folder before running npm start once. For internet hosting, configure LEUX_DATA_DIR to a persistent disk path provided by the host.

Age fit: customers enter an age in the Find a frame by age section. Admin assigns each product a Kids/Teen/Adult/All ages group and a frame size in the product form. Age provides a starting suggestion; customers should check the listed frame size. The supplied logo is logo.png.
